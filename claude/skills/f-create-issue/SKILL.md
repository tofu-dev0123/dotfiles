以下の手順でForgejo Issueを作成してください。CLIは `tea` を使用します。

## 手順

1. 引数 `$ARGUMENTS` が指定されていればトピックのヒントとして使用する

2. **壁打ち**: ユーザーにIssueの内容をヒアリングする
   - 何を報告・要望したいか
   - 背景や状況
   - 期待する結果（あれば）
   - 追加で必要な情報があれば質問を重ねる

3. **計画の提示**: ヒアリング内容を元に以下を提示し、ユーザーに確認を取る
   - **タイトル案**: 簡潔な日本語タイトル（70文字以内）
   - **本文案**: ヒアリング内容を整理した本文
   - ユーザーが修正を求めた場合は内容を調整して再提示する

4. ユーザーの承認後、`tea issues create --title "<タイトル>" --description "<本文>"` でIssueを作成する

5. 作成されたIssueのURLを表示する
