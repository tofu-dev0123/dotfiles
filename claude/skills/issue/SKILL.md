以下の手順でGitHub Issueを作成してください。

## 手順

1. 引数 `$ARGUMENTS` をトピックのヒントとして使用する（指定がなければヒアリングで確認）

2. ユーザーに以下をヒアリングする：
   - 何を報告・要望したいか
   - 背景や状況
   - 期待する結果（あれば）
   - 必要に応じて追加質問を行う

3. ヒアリング内容を元に以下を提示し、確認を取る：
   - **タイトル案**: 簡潔な日本語タイトル（70文字以内）
   - **本文案**: `${CLAUDE_SKILL_DIR}/template.md` のフォーマットに従って作成する
     （コメント `<!-- ... -->` は削除し実際の内容に置き換える）
   - ユーザーが修正を求めた場合は調整して再提示する

4. ユーザー承認後、以下のコマンドでIssueを作成する：
   `gh issue create --title "<タイトル>" --body "<本文>"`

5. 作成されたIssueのURLを表示する
