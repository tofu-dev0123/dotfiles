# グローバル設定

全プロジェクト共通の個人スタイル・ルールを定義します。

## 基本スタンス

- 回答は簡潔に。冗長な説明・要約の繰り返しは不要
- コードは変更箇所のみ。不要なリファクタや余計な改善は行わない
- コミットは明示的に依頼されたときのみ作成する

## コミット・PR の生成証跡

- コミットメッセージに `Co-Authored-By: Claude` 行を付けない
- PR 本文に `🤖 Generated with [Claude Code]` フッターを付けない
- 既存履歴は触らず、今後のコミット・PR から反映する
