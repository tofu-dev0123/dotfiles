以下の手順でプロジェクトを調査し、README.md を更新してください。

## 手順

1. **プロジェクト調査**

   Explore サブエージェントを起動して以下を調査する：
   - ディレクトリ構成（ファイルツリー全体）
   - 主要なソースファイル・設定ファイルの役割と内容
   - 使用している技術スタック・言語・フレームワーク・ライブラリ
   - セットアップ手順やスクリプト（`flake.nix`、`Makefile`、`package.json` のスクリプト等）
   - CI/CD 設定、テスト構成、ビルド方法

2. **現在の README.md を読み込む**

   Read ツールで `README.md` を読み込む。存在しない場合は「README.md が存在しない」と記録する。

3. **差分の洗い出し**

   調査結果と README の現状を比較し、以下の観点で追加・修正が必要な箇所を特定する：
   - プロジェクト概要・目的の正確性
   - 必要条件（Prerequisites）の過不足
   - セットアップ・インストール手順の正確性
   - 使い方・コマンド一覧の過不足
   - ディレクトリ構成の説明の過不足
   - その他、実態と乖離している記述

4. **プランを提示して承認を得る**

   EnterPlanMode を使い、以下の形式で更新プランをユーザーに提示する：

   ```
   ## README 更新プラン

   ### 調査結果のサマリー
   <!-- プロジェクトの概要・技術スタック・構成を簡潔にまとめる -->

   ### 現状の README の評価
   <!-- 現在の README の充実度・問題点を記述。存在しない場合はその旨を記載 -->

   ### 更新内容
   <!-- 追加・修正・削除する内容を箇条書きで列挙 -->
   - [ ] 追加: ...
   - [ ] 修正: ...
   - [ ] 削除: ...
   ```

   ユーザーの承認後、ExitPlanMode で編集を開始する。

5. **README.md を編集する**

   承認されたプランに基づき Edit または Write ツールで README.md を更新する。
   - README.md が存在しない場合は Write ツールで新規作成する
   - 日本語・英語はプロジェクトの既存スタイルに合わせる
   - 既存の記述を尊重しつつ、実態と乖離している箇所のみ修正する
