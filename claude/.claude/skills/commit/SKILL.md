以下の手順で変更をコミットしてください。

## 手順

1. **差分の収集**
   - `git status` でステージング状況を確認
   - `git diff HEAD` で全変更（未ステージ含む）を取得
   - 変更ファイルがなければ「コミットする変更がありません」と表示して終了

2. **ステージング**
   - `git add -A` で全ての変更をステージング

3. **コミットメッセージの生成**
   差分を解析し、以下のルールで日本語メッセージを生成する：
   - 1行目（タイトル）: 変更の種別 + 概要（72文字以内）
   - 種別プレフィックス: `feat:` `fix:` `refactor:` `docs:` `chore:` `style:` `test:` から選択
   - 変更が複数ファイル・複数目的にわたる場合は本文に箇条書きで補足

4. **ユーザーへの確認**
   コミットメッセージを提示した後、以下の選択肢を番号付きで表示する：

   1. このメッセージでコミット
   2. メッセージを修正する
   3. キャンセル

   - 「1」が選ばれた場合はそのままコミットを実行
   - 「2」が選ばれた場合は修正内容をユーザーに入力してもらい、メッセージを更新して再度選択肢を表示
   - 「3」が選ばれた場合はコミットせずに終了

5. **コミットの実行**
   承認されたメッセージで以下のようにコミットする：
   ```
   git commit -m "$(cat <<'EOF'
   <承認されたメッセージ>
   EOF
   )"
   ```
   コミット後、ハッシュとタイトルを表示する
