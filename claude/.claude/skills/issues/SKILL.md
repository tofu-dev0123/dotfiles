以下の手順で GitHub Issue を閲覧・選択する。CLI は `gh` を使用する。

## 手順

1. **Issue 一覧の取得**
   - `gh issue list --state open --limit 50` でオープン Issue を取得する
   - 取得した一覧を「番号・Issue番号・タイトル・ラベル」の形式で整形して表示する
     - 表示例: `1. #123 タイトル [label1, label2]`
   - Issue が 0 件なら「オープンな Issue はありません」と表示して終了する

2. **番号選択**
   - 一覧の番号（リスト上の通し番号）を入力してもらう
   - `q` / `cancel` / 空入力などで終了する
   - 範囲外の番号なら再入力を促す

3. **詳細表示**
   - 選択された通し番号から対応する Issue 番号を特定する
   - `gh issue view <issue-number>` で内容を取得し、タイトル・本文・ラベル・担当者・状態を整形して表示する

4. **次のアクション選択**
   - 詳細表示後、以下の選択肢を番号付きで提示する：
     1. 壁打ちする（議論・設計相談）
     2. 実装を開始する（ブランチを切る）
     3. 終了する
   - 選択に応じて手順 5・6・終了のいずれかに進む

5. **壁打ちモード**
   - Issue の内容に沿って対話で議論する
   - 必要に応じて関連コードを調査したり設計案を提示したりする
   - ユーザーが実装に進みたいと言った場合は手順 6 に遷移する

6. **実装モード**
   - 以下を順に実行してブランチを準備する：
     1. `git status` で作業ツリーがクリーンか確認する（未コミットの変更があれば警告し、続行可否をユーザーに確認する）
     2. `git checkout develop` で develop に切り替える
     3. `git pull origin develop` で develop を最新化する
     4. `git checkout -b feature/issue#<issue-number>` でブランチを作成する
        - `#` を含むブランチ名は有効だが、コマンド上はダブルクォートで囲む
   - 作成したブランチ名を表示し、「実装準備完了」と通知する
   - 以降は自由会話で実装を進める
